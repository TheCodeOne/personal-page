# Repository-Informationen

Dieses Repository enthält den Quellcode für eine persönliche Webseite/Portfolio-Seite. Es basiert auf dem Astro-Theme **Astro Micro** (einem leichtgewichtigen, barrierefreien Theme ohne Standard-Frameworks, erweitert mit Features wie Pagefind für die Suche und Giscus für Kommentare).

## Wo liegen die Blog-Artikel?

Die Artikel (Blog-Posts) befinden sich im folgenden Verzeichnis:
- [src/content/blog/](file:///Users/dimi/Documents/git/astro-micro/src/content/blog/)

Die Blog-Beiträge sind in Form von Markdown- (`.md`) und MDX-Dateien (`.mdx`) abgelegt und werden von Astro über die Content Collections API dynamisch gerendert.
